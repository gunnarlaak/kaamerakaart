# kaamerakaart
Eesti ametlik allikas avaldab perioodiliselt uuenevaid teekaamera pilte, mitte katkematut videovoogu. Kõigi maailma avalike veebikaamerate täielikku keskregistrit pole olemas, kuid rakendusele saab hiljem lisada täiendavaid riike ja andmepakkujaid. Andmed pärinevad Transpordiameti Tark Tee avatud andmetest ja nende DATEX II kirjeldusest.
